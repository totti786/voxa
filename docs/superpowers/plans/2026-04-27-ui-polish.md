- [ ] **Step 1: Write helper to distribute angles excluding bottom arc**

In `web/src/ui/participants.ts`, add a helper function before `renderParticipants`:

```typescript
function distributeAnglesAvoidingBottom(
  index: number,
  total: number
): number {
  // Exclude bottom 90° (π/2 ± π/4), i.e. angles from π/4 to 3π/4
  // Usable arc: [ -3π/2, π/4 ] ∪ [ 3π/4, π/2 ] ... easier:
  // Map 0..1 onto the full circle minus the excluded bottom wedge.
  // Excluded wedge center = π/2, half-width = π/4.
  // Total usable = 2π - π/2 = 3π/2.
  const excludedCenter = Math.PI / 2;
  const excludedHalfWidth = Math.PI / 4;
  const excludedWidth = excludedHalfWidth * 2; // π/2
  const usableArc = Math.PI * 2 - excludedWidth; // 3π/2

  const raw = (index / Math.max(total, 1)) * usableArc;
  // Shift so that index 0 starts at top (-π/2)
  let angle = raw - Math.PI / 2;

  // If angle falls inside the excluded zone, push it past
  const excludedStart = excludedCenter - excludedHalfWidth; // π/4
  const excludedEnd = excludedCenter + excludedHalfWidth;   // 3π/4

  // Normalize to [-π, π] for comparison
  if (angle > excludedStart && angle < excludedEnd) {
    angle = excludedEnd;
  }

  return angle;
}
```

Actually, a cleaner approach — just distribute across the usable arc directly:

```typescript
function distributeAnglesAvoidingBottom(
  index: number,
  total: number
): number {
  // Usable arc excludes bottom 90° (π/2 ± 45°)
  // Start from top (-π/2), go clockwise around to just before π/4,
  // then resume after 3π/4 back to -π/2.
  // Total usable = 2π - π/2 = 3π/2
  const usable = (Math.PI * 3) / 2;
  const t = index / Math.max(total, 1);
  const angle = -Math.PI / 2 + t * usable;

  // If we crossed into the excluded zone (π/4), skip past it
  if (angle > Math.PI / 4) {
    return angle + Math.PI / 2; // skip the excluded 90°
  }
  return angle;
}
```

```typescript
function logScaleBin(i: number, total: number, maxBin: number): number {
  const minFreq = 1; // avoid log(0)
  const logMin = Math.log(minFreq);
  const logMax = Math.log(maxBin);
  const t = i / Math.max(total - 1, 1);
  const logVal = logMin + t * (logMax - logMin);
  return Math.min(Math.floor(Math.exp(logVal)), maxBin - 1);
}
```
